# WAJ

WAJ builds business software for salons, spas and clinics, and the AI that runs inside it. This is where our open-source work lives.

## Open source

| Project | What it is |
|---|---|
| [**ai-engine**](https://github.com/waj-1/ai-engine) | WAJ AI Engine: the self-hosted agent platform your AI assistant can operate. Build, test and ship agents over MCP, or from a portal. Apache-2.0. |
| [**waj-plugin**](https://github.com/waj-1/waj-plugin) | WAJ plugin for Claude and ChatGPT: run a salon, spa or clinic from your AI assistant. |
| [**waj-features**](https://github.com/waj-1/waj-features) | Short videos and illustrated guides for every part of the WAJ app. |

## Get involved

- Try the engine in your browser, no sign-up: [engine-demo.waj.ai](https://engine-demo.waj.ai)
- Run it yourself: `git clone https://github.com/waj-1/ai-engine && cd ai-engine && docker compose up`
- Ask a question or share what you built in [Discussions](https://github.com/waj-1/ai-engine/discussions)
- Pick up a [good first issue](https://github.com/waj-1/ai-engine/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
